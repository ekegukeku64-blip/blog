## ✨ New: the story check

Clips used to be picked from the sound alone. Sometimes the hook promised something that never
showed up, or the cut stopped one second before the punchline. Now your AI **looks at the frames**
of every moment before it cuts:

- 🎬 **The whole scene.** Each clip starts 3-10 seconds before the crazy thing happens and ends right after the streamer's reaction.
- 🎯 **Hooks that match the picture.** If the hook says something the video doesn't show, it gets rewritten. If nothing worth posting is on screen, a backup moment takes its place.
- 🔥 **Reaction first.** It ranks moments by how hard the streamer loses it (screaming, laughing, jumping up), then makes sure you see what caused it.
- 💬 **Real captions.** What the streamer says stays as it is. Only slurs are starred out in the on-screen text (TikTok and Reels flag them and bury the post). The audio is never changed.


  


Works the same in Claude and ChatGPT (and Kimi, Gemini or no AI at all). Nothing new to learn: you ask for clips exactly like before.

## 🛠️ How it works


  


1. **You say** *"Make GTA 6 clips"* to Claude or ChatGPT.
2. **It asks three questions:**
   - How many clips? *(default 4)*
   - Streams from the last **24 hours**, **48 hours** or **1 week**? *(default 48 hours)*
   - Which style? It shows you the five styles. Pick one, several, or all. *(default: Hook card)*
3. **It shows you the most viewed streams** with views and age. Pick some, or say *"take the top ones"*.
4. **It does the work** (about 10-20 minutes per stream) and tells you what it's doing.
5. **You get a folder of finished reels** plus a `POSTING.md` with the caption and hashtags for each one.
6. **You post them** to the campaign and collect.

| Step | What happens behind the scenes |
|---|---|
| 🔎 **Finds the streams** | Searches YouTube for the most viewed GTA 6 streams in your time window, skips re-uploads and compilations, checks the language. |
| 👀 **Watches the whole stream** | Looks at the entire stream in seconds and skips waiting rooms, menus and just chatting. Only real gameplay. |
| 👂 **Listens for the hype** | Finds the moments where the streamer screams, laughs and chat explodes. |
| 🧠 **Picks the viral moments** | Your AI chooses the funniest, most shocking moments and writes a hook for each. |
| ✂️ **Cuts only what it needs** | Downloads only those seconds of video (plus a little extra on each side), not the whole 10 hours. |
| 🎞️ **Checks the story** | Looks at the frames and re-cuts each moment so it shows the whole scene, from just before the surprise to the end of the reaction. Rewrites a hook that doesn't match the picture. |
| 🎬 **Edits like a pro** | 9:16, hook text, word-by-word captions, zooms and sound effects in 5 styles. |
| ✅ **Checks its own work** | Looks at every finished reel before handing it to you. |

## 🎨 Five viral styles


  


| # | Style | What it looks like | Best for |
|---|---|---|---|
| **1** | **Hook card** ⭐ default | Story sentence on top with the action words in **red**, gameplay in the middle | Shocking moments, NPC chaos, discoveries |
| 2 | **Stack** | Streamer in a framed box on top, hook text on a divider line, then the **full game screen** below | Big reactions |
| 3 | **Bubble** | Full-screen gameplay, streamer's face in a circle at the bottom | Fast hype moments |
| 4 | **Cinematic** | Movie look, slow zoom, quiet subtitles | Beautiful or emotional scenes |
| 5 | **Breaking news** | BREAKING headline and a red ticker | Secrets, hidden features, big finds |

Every reel is **1080×1920**, keeps text away from the TikTok/Reels buttons, and still looks
right in Instagram's 4:5 feed crop.

## 🚀 Quick start

**You need:** a Mac or Windows PC, about 3 GB free, and **Claude** (Claude Code / Claude
desktop app) or **ChatGPT** (desktop app with Codex). The normal claude.ai / chatgpt.com
websites can't run it.

**1. Install two free tools** (Terminal on Mac, PowerShell on Windows):

```bash
# Mac
brew install ffmpeg deno
```

```powershell
# Windows
winget install Gyan.FFmpeg
winget install DenoLand.Deno
```

**2. Add the skill:**

```bash
# Claude
git clone https://github.com/beyondtahir/beyondgtaclips ~/.claude/skills/beyondgtaclips
# ChatGPT (Codex)
git clone https://github.com/beyondtahir/beyondgtaclips ~/.codex/skills/beyondgtaclips
```

On Windows the folders are `C:\Users\\.claude\skills\` and `C:\Users\\.codex\skills\`.

**3. Say** *"set up beyondgtaclips"* (once, about 5 minutes), then *"make GTA 6 clips"*. 🎉

ChatGPT will ask for permission to use the internet and save files: choose **Allow**.

## ❓ FAQ


Is it really free?

Yes. Everything runs on your own computer: speech recognition, editing and rendering.
No API keys, no credits, no subscription. The AI that picks the moments is the Claude or
ChatGPT you already use.


Will I definitely make money?

No tool can promise that. The money comes from views, and views come from posting good clips
fast and often. This tool removes the slow part (finding and editing) so you can post more,
faster. Read each campaign's rules before you post.


Does it work without any AI?

Yes. With no AI it picks moments from the loudest, most hyped parts of the stream. The AI
makes the picks and hooks much better, so we recommend using it.


Can it clip a stream that is still live?

Not yet: YouTube only allows cutting parts of a stream after it ends (usually within an hour).
It lists live streams separately so you can come back for them.


Twitch and Kick?

Yes, by link, or add your favourite creators to `~/BeyondGTAClips/watchlist.txt`.
The automatic search uses YouTube.


Other games?

Yes. Say *"make Fortnite clips"* (or any game). GTA 6 is just the default.

## 🧰 For developers

The engine is plain Python + ffmpeg + Pillow (all text is drawn with Pillow, so it looks the
same on every computer). Run it directly:

```bash
python3 scripts/beyondgtaclips.py setup
python3 scripts/beyondgtaclips.py styles
python3 scripts/beyondgtaclips.py find --within 48h
python3 scripts/beyondgtaclips.py clip --pick 1,2 --total 4 --styles 1
python3 scripts/beyondgtaclips.py remake "" --clip 2 --hook "New *hook* here"
```
