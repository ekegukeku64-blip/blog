# 🖥️ Windows Animated Wallpapers

**High-Quality Live Wallpapers for Windows — 2026**

A curated collection of smooth, lightweight animated wallpapers optimized for Windows 10 and 11. 
No heavy engines, no lag — just clean motion for your desktop.

---

## 🎯 What it is

**Windows Animated Wallpapers** is an open-source collection of live backgrounds designed specifically for the Windows desktop environment. 
Unlike heavy third-party engines, these wallpapers are optimized for low CPU/GPU usage, making them perfect for developers and gamers.

> 💡
> Works seamlessly with Windows 10/11. Supports 1080p, 1440p, and 4K resolutions.

## 🚀 Quick Start


  
    
  


1. Download the project using the button above.

## 🧩 How to use

1. Download and extract the archive.
2. Run **WallpaperSetup.exe**.
3. Browse the `wallpapers/` folder to preview files.
4. Select a wallpaper and click "Set as Desktop Background".
5. Right-click the tray icon to adjust performance settings.

---

## ⚙️ Configuration

All settings are available in the system tray menu:

- **Performance Mode**: Balanced / High Quality / Battery Saver.
- **Pause on Fullscreen**: Automatically stops animation when gaming.
- **Startup**: Launch with Windows.
- **Audio Reactivity**: Sync animations with system audio (optional).

## ❓ FAQ

**Will this slow down my PC?**
No — the wallpapers use hardware acceleration (WebM/MP4) and automatically pause when you open a fullscreen app or game.

**Does it work on Windows 10?**
Yes, it supports both Windows 10 (version 1903+) and Windows 11.

**Can I add my own videos?**
Yes — just drop `.mp4` or `.webm` files into the `wallpapers/` folder.

**Is it safe?**
Yes, it's fully open-source. You can inspect the code and build it yourself.
