# 墨迹博客

个人技术博客，基于 [Astro](https://astro.build) 构建，部署在 [GitHub Pages](https://pages.github.com/)。

## 本地开发

```sh
npm install
npm run dev
```

访问 `http://localhost:4321`。

## 构建

```sh
npm run build
```

## 部署

手动部署：

```sh
bash deploy.sh
```

自动部署：推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages。
